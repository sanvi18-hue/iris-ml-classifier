# iris-ml-classifier
# Iris Flower Classifier

A machine learning model that classifies iris flowers into 3 species based on their measurements, built using scikit-learn.

## What it does
Takes flower measurements (sepal length, sepal width, petal length, petal width) and predicts the species: setosa, versicolor, or virginica.

## How it works
- Uses the classic Iris dataset (150 samples)
- Trains a Random Forest Classifier on 80% of the data
- Tests accuracy on the remaining 20%
- Achieves ~93-100% accuracy

## How to run
Open `iris_flower_classifier.ipynb` in Google Colab and run each cell in order.

## What I learned
Built this to understand the basics of machine learning: train/test splits, how classifiers work, and how to measure model accuracy.
